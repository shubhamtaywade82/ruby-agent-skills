# Routing Model Matrix Contract

Protocol version: 1

The model matrix describes planned provider/model executions over the same public routing corpus.

A model entry must be an explicit runtime configuration. The matrix is not a prediction or ranking system.

## Comparability controls

Every executed model must use:

- the same public routing case corpus;
- the same repetition count;
- the same per-run timeout;
- fresh workspace isolation;
- the same routing contract and result protocol.

Each model campaign is independently verified, evidenced, and archived before any descriptive comparison is made.

No model may be compared solely because it is listed in the matrix. Unexecuted models have no result.
