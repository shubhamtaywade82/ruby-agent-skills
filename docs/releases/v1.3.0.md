This release covers Iterations 156–158 (see `CHANGELOG.md`). It is the first release in which every skill conforms to the Agent Skills specification.

### Agent Skills specification and single-skill installs

Every skill now passes the official Agent Skills validator (`skills-ref`) and declares `license: MIT`. Fifteen skills previously carried a top-level `family:` field that the specification does not allow; it is removed, and the validator now rejects any field outside the specification.

Each skill can be installed on its own with `npx skills add shubhamtaywade82/ruby-agent-skills --skill <name>`. Skills name other skills and patterns instead of pointing at repository paths, so nothing breaks in a single-skill install. `bin/install` remains the way to get the full pack, including the pattern catalog.

### New verification rules

Owning skills now require:
- a failing query-count test before N+1 fixes;
- rerunnable engine install generators;
- no-JavaScript Hotwire baselines;
- characterization tests before refactors;
- rerunnable seeds with no secrets;
- tested authorization denial.

`change-review` flags a fixed list of security patterns as always critical. GraphQL (graphql-ruby) work is now covered by `rails-api-integration`.

### New tools

- `bin/skills-spec-check` runs the pinned official validator over every skill (also in CI).
- `bin/publish-readiness` runs every deterministic publishing check and writes an evidence report. `docs/PUBLISHING.md` describes the full evaluation plan.
- The Release workflow attaches the verified archive to a release that already exists, and can be run manually for an existing tag (`RELEASE.md`).
