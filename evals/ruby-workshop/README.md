# Ruby Workshop and Rails Book Evaluations

This evaluation family turns the practical material from the Ruby/Rails source books into agent tasks with executable contracts.

Cases:

- enumerable-transform
- method-contract
- voting-application
- service-object
- external-api-client
- ruby-gem-boundary
- rails-rest-contract
- rails-authentication-boundary

The cases intentionally cover different agent behaviors: Ruby collection selection, public API contracts, object-oriented application design, service boundaries, external API isolation, gem packaging, REST resource design, and authentication boundaries.

Public evaluation YAML is reproducible benchmark input. Private hidden cases should remain outside the repository.
