# Security

Security-sensitive issues should not be disclosed with exploit details in public issues or pull requests.

Use the repository's available private GitHub security-reporting channel when available. Include enough information to reproduce the issue safely, the affected boundary, and the relevant version or commit.

For Rails-specific security engineering and scanner usage, see [`docs/SECURITY.md`](docs/SECURITY.md).

This project does not treat automated scanner output as a security verdict. Findings require data-flow, trust-boundary, and regression-test analysis.
